# Credits

This standalone game retains the selected assets and MIT camera/math/RNG implementation extracted
from [td01](https://github.com/matapao/td01). Models and font licenses are included under `public/`.
The historical collection index is retained in KAYKIT_IMPORTED_INDEX.md; only the selected files ship.

- Knight and medium-rig animation library: Kay Lousberg, KayKit character collection, CC0.
- Cinzel: Natanael Gama, SIL Open Font License 1.1.
- Alegreya: Juan Pablo del Peral / Huerta Tipográfica, SIL Open Font License 1.1.

The applicable KayKit text licenses are copied into production `assets/licenses/`. Font licenses
remain alongside their production font files. No audio is shipped in this Alpha.
